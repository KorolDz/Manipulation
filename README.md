# Deepfake Detection System

Desktop-приложение для локального анализа аудио и видео на признаки цифровой манипуляции.

## Возможности
- проверка аудио: `.wav`, `.mp3`;
- проверка видео: `.mp4`, `.avi`, `.mov`;
- загрузка и предварительная обработка медиафайлов перед анализом;
- локальный запуск моделей без передачи файлов сторонним сервисам;
- визуальный отчет о достоверности файла и обнаруженных несоответствиях;
- экспорт текущего отчета в PDF;
- сохранение истории проверок и отчетов в SQLite;
- кэширование загруженных ML-моделей для ускорения повторных проверок;
- PySide6-интерфейс с отдельными слоями UI, сервисов и ядра.

## Структура проекта
- `main.py` — точка входа приложения;
- `app/core/` — константы, модели данных, парсинг результата;
- `app/services/` — валидация, предобработка, запуск анализа, SQLite-репозиторий;
- `app/ui/` — PySide6-окно, worker-поток и стили;
- `audio_detection/` — анализ аудио;
- `video_detection/` — анализ видео;
- `weights/` — веса моделей.

## SQLite
База создается автоматически при запуске:

```text
data/app.sqlite3
```

В базе хранится только история проверок и отчетов: путь к файлу, имя, тип, размер, длительность, технические параметры, статус, результат, вероятность, текст ответа модели и список обнаруженных несоответствий.

## Основные функции по ТЗ
- Загрузка и предварительная обработка: приложение проверяет формат, собирает метаданные файла, длительность и технические параметры аудио/видео.
- Визуализация отчета: после анализа отображается итог, вероятность, параметры файла и список найденных замечаний.
- Экспорт отчета: текущий отчет можно сохранить в PDF через кнопку `Экспорт PDF`.
- База проверенных файлов: все проверки сохраняются в SQLite, а отчет можно восстановить из таблицы истории.

## Установка и запуск
1. Создать окружение:
   ```bash
   python -m venv venv
   ```
2. Активировать окружение в Windows:
   ```bash
   venv\Scripts\activate
   ```
3. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустить приложение:
   ```bash
   python main.py
   ```

## CLI-режим
GUI запускается без аргументов:

```bash
python main.py
```

Анализ одного файла:

```bash
python main.py --analyze "H:\Загрузки\test_data\newsfake.mp4"
```

Анализ всех поддерживаемых файлов в папке:

```bash
python main.py --folder "H:\Загрузки\test_data"
```

Анализ папки вместе с вложенными каталогами:

```bash
python main.py --folder "H:\Загрузки\test_data" --recursive
```

CLI сохраняет результаты в ту же SQLite-базу `data/app.sqlite3`, что и desktop-интерфейс.
