# Deepfake Detection System

Desktop-приложение для локального анализа аудио и видео на признаки цифровой манипуляции. Программа проверяет медиафайлы с помощью моделей машинного обучения, показывает результат в графическом интерфейсе, сохраняет историю проверок и позволяет экспортировать отчет в PDF или HTML.

## Возможности

- проверка аудиофайлов в форматах `.wav`, `.mp3`;
- проверка видеофайлов в форматах `.mp4`, `.avi`, `.mov`;
- предварительная обработка медиафайлов перед анализом;
- локальный запуск моделей без передачи файлов сторонним сервисам;
- отображение результата проверки, вероятности и пояснений;
- сохранение истории проверок в SQLite;
- экспорт текущего отчета в PDF и HTML;
- CLI-режим для анализа одного файла или папки с файлами.

## Требования

- Python 3.11;
- pip;
- зависимости из файла `requirements.txt`;
- файлы моделей в папке `weights/`:
  - `weights/audio_deepfake_v1.h5`;
  - `weights/efficient_weights.weights.h5`;
- файл каскада лиц `haarcascade_frontalface_default.xml`.

## Установка и запуск

1. Склонировать репозиторий и перейти в папку проекта:

   ```bash
   git clone <URL репозитория>
   cd Manipulation
   ```

2. Создать виртуальное окружение:

   ```bash
   python -m venv venv
   ```

3. Активировать виртуальное окружение в Windows:

   ```bash
   venv\Scripts\activate
   ```

4. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

5. Запустить приложение:

   ```bash
   python main.py
   ```

После запуска откроется desktop-интерфейс PySide6. В нем можно выбрать аудио- или видеофайл, выполнить анализ, посмотреть результат и экспортировать отчет.

## CLI-режим

GUI запускается без аргументов:

```bash
python main.py
```

Анализ одного файла:

```bash
python main.py --analyze "path\to\file.mp4"
```

Анализ всех поддерживаемых файлов в папке:

```bash
python main.py --folder "path\to\folder"
```

Анализ папки вместе с вложенными каталогами:

```bash
python main.py --folder "path\to\folder" --recursive
```
